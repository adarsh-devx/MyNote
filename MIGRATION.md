# TypeScript Migration

The MVP starter has been converted from JavaScript to TypeScript.

## Frontend
- React + TypeScript + Vite
- `.tsx` components
- `types/note.ts`
- strict TypeScript enabled
- component-based structure
- Vite config is `vite.config.ts`

## Backend
- Express + TypeScript
- `src/server.ts`
- strict TypeScript enabled
- `tsx` for development
- `tsc` for production build

## Important
The previous JavaScript implementation should not be mixed back into the project.
