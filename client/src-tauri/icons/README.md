# Tauri Icons

This directory contains the Windows application icons for MyNotes.

## Required Files

- `32x32.png` — 32×32 pixels
- `128x128.png` — 128×128 pixels
- `128x128@2x.png` — 256×256 pixels
- `icon.icns` — macOS icon (if building for macOS)
- `icon.ico` — Windows icon

## How to Generate

Use the Tauri icon generation tool:
```bash
npm run tauri icon path/to/your/logo.png
```

This will generate all required icon sizes from a single source image.
