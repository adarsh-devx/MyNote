# PWA Icons

This directory should contain the following icons for the MyNotes PWA:

## Required Sizes

- `icon-192.png` — 192×192 pixels
- `icon-512.png` — 512×512 pixels
- `icon-maskable-512.png` — 512×512 pixels (for maskable icon)

## Design Guidelines

- Use the MyNotes brand style
- Warm off-white background (#f7f6f2)
- Near-black text/borders (#111111)
- Simple, recognizable design
- Keep it minimal and clean

## How to Create Icons

1. Start with a 512×512 design
2. Export as PNG
3. Resize to 192×192 for the smaller icon
4. Ensure the maskable icon has safe zone padding
